    Our primary evaluation, procedural adversarial evaluation (PAE), is a worst-case search against each network after it has completed training; we describe this in the following subsections. The true worst case cannot be computed with a finite number of queries, so we use best-effort adversaries that probe each model as a black box subject to a compute budget, and we refer to the worst case an adversary finds as theevaluation worst case. We consider two PAE adversaries: a single-model adversary that searches against each model separately, and a cross-model adversary that pools the worst cases found across models. We also evaluate every model on the same test set of 65,536 scenes sampled uniformly at random.

    Canonical source evidence
    Our single-model evaluation protocol uses a black-box optimizer to search for the procedural pa- rameters that produce the worst loss for a given network. We use a budget of 2 million queries, which represents39%of the overall training budget of 5.12 million samples. We split this between 1 million samples of a DIRECT-L search (Gablonsky & Kelley, 2001) and 1 million samples of a CMA-ES search. This CMA-ES search differs from the search performed during training in several important ways: (1) it uses a population size of 512 instead of 28 (2) it updates a full covariance matrix instead of a diagonal parameterization (3) IPOP restarts are permitted (4) the objective is stationary, allowing for better convergence (Hansen et al., 2019). Combined, these settings give the evaluation a substantially more powerful search than training.
