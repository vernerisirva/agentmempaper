Abstract / summary

Source code, trained models, and experimental data for the first systematic benchmark of 8 memory decay architectures for LLM agent systems. Evaluates LTC, CfC, Neural ODE, CCT-LNN, GRU, GRU+Time, Transformer, and Parametric ExpDecay across 3 datasets with 5-fold cross-validation.
