AI assessment inconclusive

The paper tackles clear failure modes of point-cloud-driven pseudo-labeling in multi-view 3D detection with principled, well-ablated components and demonstrates substantial empirical improvements on standard benchmarks without circular evaluation.

The manuscript could further explore sensitivity to depth map quality used during the offline single-view proposal step, though reliance on heavy pretrained models (Cubify Anything, SAM, Qwen3-VL) is properly noted as strictly offline training preparation.

    Recent open-vocabulary multi-view indoor 3D detection methods typically follow a point-cloud-driven pipeline, where pseudo 3D boxes are generated from reconstructed or estimated geometry and semantic labels are inferred from projected regions. However, such a design makes box generation dependent on the completeness of point clouds and restricts semantic learning to local appearance, caus- ing inferior 3D object localization and open-vocabulary classification. In this paper, we present See and Detect, an image-driven framework that uses multi-view images as the primary evidence for 3D box and semantic label generation. For box generation, we first discover object candidates from individual images, enabling objects missing in point clouds to be recovered from visual evidence.
