  • Limitations and uncertainty handling — page 9

    The authors acknowledge that retrieval relevance peaks at 45.0%, tag overlap at 35.5%, LOCOMO evaluation uses a single pass, and public memories can be altered with factually incorrect information.

    Attributed source statement: supported. The limitations section explicitly identifies weak retrieval and tag metrics, single-run LOCOMO comparison, and public-memory integrity risks. These are substantive, specific limitations tied to measured results rather than generic caveats. Claim/evidence check: supported.

    Canonical source evidence
    Our evaluation has several limitations. First, tag overlap (35.5% on the best model; full results in Table 2) is notably lower than other content metrics, suggesting that AIM's tag extraction strategy needs refinement. Additionally, retrieval relevance peaks at 45.0% (Table 2). Lastly, our LOCOMO evaluation (Table 5) uses a single pass, whereas Mem0 reports averages over 10 runs. This could reduce statistical significance of claims. Additionally, LOCOMO is a single-user benchmark and does not exercise AIM's multi-user privacy classification or cross-agent synchronization—the features that most differentiate it from existing systems. Further work must be conducted to improve memory retrieval, such as changing the number of retrieved memories before filtering. In terms of security, another limitation is the ability of users to create or alter public memories with factually incorrect
    information. The current scope of public memories is all users, and thus any individual can add or edit public memories with information that is not factual.
