However, this capability also introduces a new attack surface:mem- ory poisoning, where adversaries can inject malicious information to influence future behavior. In this paper, we proposeMemPoison, a novel memory poisoning attack that bypasses selective memory mechanisms in LLM agents, where an attacker can inject triggerable backdoors into the agent's long-term memory through dialogue interactions, thereby mis- leading its subsequent responses.
