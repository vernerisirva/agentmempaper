Abstract / summary

Large language model (LLM) agents that serve users across many sessions must choose, for every request, the few stored memories that enter a limited context window. Quality reviewed

The work provides a sound theoretical formulation uniting memory architectures into a recommender cascade and demonstrates strong empirical gains using zero-LLM-call ranking, supported by thorough baseline reproductions, cost measurements, and independent evaluation controls.

The authors identify degradation on instances requiring evidence across three or more sessions (kappa >= 3), sensitivity to near-miss filler distractors in complete slates, and performance variations across target answering models.
