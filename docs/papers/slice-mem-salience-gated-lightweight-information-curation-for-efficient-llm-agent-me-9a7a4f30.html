Abstract / summary

Long-term memory enables large language model (LLM) agents to maintain personalized and temporally coherent interactions, but repeated LLM inference for memory admission, extraction, and organization introduces substantial cost and latency. The study offers a rigorous, well-controlled evaluation of an efficient long-term memory architecture with detailed ablations, honest discussion of negative or mixed consolidation impacts, and clear methodological documentation.

The authors transparently document limitations, including restriction to user turns, performance plateaus/drops from offline consolidation on certain tasks, lack of heterogeneous external document support, and reliance on proxy diagnostics.

    After online memory construction, SLICE-Mem performs offline consolidation to identify redun- dant or outdated information among stored entries [7, 22]. It updates entry statuses to guide sub- sequent retrieval while preserving the original text, embeddings, and timestamps, without deleting or rewriting memories. The procedure begins with deterministic rules for clear duplicates and changes in mutually exclusive personal attributes. Duplicate detection considers whether entries refer to the same occurrence, so similar descriptions of separate events remain available. State changes are processed in timestamp order, allowing a return to an earlier value to be retained as a new transition.
