    Time-aware retrieval is crucial for long-horizon LLM agents to effectively leverage ever-growing long-term memory. Existing methods focus on lexical or semantic similarity, leading to target memories being crowded out by temporally mismatched yet semantically similar candidates. Even time-aware approaches inject temporal cues only during memory organization or answer generation, overlooking tempo- ral constraints at the retrieval stage, where candidate selection occurs—the root cause of the displacement. Inspired by the temporal contiguity effect in human episodic memory, we proposeTIDER(TemporalInterval-drivenDual-channel EvidenceRetrieval), a time-aware agentic retrieval framework.     Canonical source evidence
    TIDER is a time-aware agentic retrieval framework for long-term memory QA that decouples temporal constraints from the semantic embedding space and expresses them as explicit temporal windows. The pipeline is built around a reinforcement-learned locatorπθ: given a query and a timeline summary, πθ predicts the windows that contain the required evidence (Section 3.1). The predicted windows define an independent temporal channel that runs in parallel with the always-on semantic channel, and the merged candidates are reranked by their temporal distance to the predicted windows (Section 3.2). The locator is trained with a composite reward over temporal need, window localization, evidence coverage, and answer correctness (Section 3.3). When the query is non-temporal, πθ closes the temporal channel, and TIDER falls back to the semantic retrieval.
