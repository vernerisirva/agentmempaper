    Sparse query-based 3D detectors commonly encode heterogeneous semantic, geo- metric, and motion information into unified latent queries, including when explicit 3D anchors are used. We introduce ExQuery, an explicit structured query framework for temporal 3D object detection. Each decoded query is organized into a shared semantic- context slice and physical-state-specific slices for center, dimensions, orientation, and velocity. This structure is preserved from prior encoding to branch-specific regression and is reused to reconstruct temporal queries: predicted physical states are transformed by ego motion, classification scores form soft semantic priors, and the reconstructed query is fused with the stored latent instance feature through gated affine modulation.     We presented ExQuery, which preserves a shared/physical channel organization in 3D object queries from explicit prior encoding to temporal reconstruction and branch-specific regres- sion. Experiments show competitive detection performance, while the ablations support the complementary roles of structured queries, explicit priors, and gated fusion. Despite these encouraging results, several directions remain open for further exploration. In our current design, the shared semantic-context slice is intentionally used by all prediction branches, allowing physical prediction to benefit from contextual cues. The added query en- coders and fusion module also introduce a measurable latency cost.
