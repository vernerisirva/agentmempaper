Abstract / summary

Open-vocabulary object detection (OVD) is essential for detecting objects beyond the categories seen during training. Establishing vision-language associations is crucial for recognizing unseen categories, while integrating complementary visual features across levels supports detection at different scales. The paper provides a well-motivated architectural enhancement with mathematically clear design details, comprehensive ablation studies across multiple base models, and consistent empirical gains across standard open-vocabulary detection and segmentation benchmarks.

The manuscript notes that novel-category pseudo-label coverage does not directly capture pseudo-label precision [E3825d446b707601b-B0062] and relies on established pre-trained vision-language backbones.
