Quality reviewed

The work presents a rigorous cryptographic definition, sound proofs, a functional reference implementation, and thorough empirical experiments exploring security and utility trade-offs without overclaiming.

The authors explicitly discuss limitations, including plaintext leakage of the lineage graph structure, restriction to models up to 7B parameters, dependence on seeing full prompt contexts, and the necessity of re-derivation or small-context writing to mitigate utility loss.

Deleting a message is therefore not enough: its derivatives, storage residue and backups survive. We definelineage-complete forward-secure erasure: after a forget request, an adversary that later obtains all storage and the agent's current keys learns nothing about the forgotten input or any memory derived from it. We present LinEra, which encrypts each memory under a key derived from its parents' keys along the derivation graph; source keys come from a puncturable pseu- dorandom function, so forgetting is a single puncture and every descendant becomes unreadable without being located.
