Quality reviewed

The study offers a rigorous, well-controlled experimental framework for an under-evaluated task in agent architectures. The pairing with control dialogues prevents degenerate solutions (such as total memory wipe or failure to store) from appearing successful, accompanied by human judge validation and statistical uncertainty analysis.

The authors document key limitations including the purely synthetic nature of the multi-session dialogues and restriction to conversational memory without evaluating tool caches, external logs, or web-service traces.

    Long-term memory has become a core component of large language model (LLM) agents. As agents accumulate personal information over long-term use, users in- creasingly ask them to delete sensitive or outdated facts. A memory system should honor such requests. It should remove exactly what was requested and keep the rest of its memory intact. However, existing memory benchmarks evaluate only memory writing, retrieval, and organization, so whether agents can forget at the user's explicit request remains under-evaluated. To address this gap, we propose BEMULA, the first benchmark dedicated to memory unlearning. It comprises 50 multi-session dialogue instances, 135 forget requests of six types, and 1,742 test questions.     We have presented BEMULA, the first benchmark dedicated to memory unlearning in LLM agents. Evaluations of six memory systems and the Full Context LLM under up to three backbone LLMs show a consistent pattern. Systems retain target information reliably, yet forgetting on demand largely fails, and almost no request passes its full suite. Memory unlearning therefore remains an open challenge. Our study has two limitations. The dialogues are synthetic and come from one generation pipeline, and the benchmark covers conversational memory only, whereas tool-using agents can leave forgotten values in caches, logs, or external services. Extending BEMULAto real- user dialogues and tool use is a natural next step. 9 Preprint.

    ETHICS STATEMENT BEMULAcontains only synthetic data. All user profiles, facts, and dialogues are produced by an LLM pipeline and do not describe any real person, so the benchmark creates no privacy risk for individuals. The attack suite includes prompt-based extraction techniques such as jailbreak prefixes, and we use them only to measure whether memory systems leak deleted information. The bench- mark is intended to encourage defenses against such extraction. Since the grading relies on an LLM judge, its verdicts may carry model biases. We mitigate this risk with a human validation of the LLM judge on 100 sampled items, which yields 98% agreement. We expect the benchmark to have a positive societal impact as well.
