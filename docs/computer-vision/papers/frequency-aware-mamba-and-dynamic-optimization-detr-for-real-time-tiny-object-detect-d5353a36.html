Abstract / summary

Abstract 实时微型物体探测是低空无人飞行器(UAV)感知的关键任务。然而,由于成像高度、视角和复杂背景的变化,空中目标通常体积小、分布密集且视觉模糊,从而对检测精度和推理效率构成了巨大挑战。尽管RT-DETR框架提供了端到端的检测模式,但它对微小物体的反应较弱,特征融合过程中细微细节的退化,以及无人机场景中不稳定的边界箱回归。为应对这些限制,我们的FAMO-DETR被引入为一种频率感知的端到端探测器,专为通过无人机探测微小物体而设计。具体而言,通过离散的小波变换,将频率感知的Mamba编码器(FAME)设计用于将低频语义信息与高频边缘细节分离,从而通过Mamba序列建模,增强深度特征中的全局情境表示。随后开发出一种高频...
