Quality reviewed

This study makes a well-controlled, significant contribution to understanding and mitigating failure modes in agent memory architectures. The experimental design is meticulous with sound comparative baselines and well-scoped claims.

The authors acknowledge key limitations, including the reliance on benchmark-provided source annotations, synthetic seeds placed into historical traces, answer span selection influencing gains, and lack of human audit for borderline judge scores.

    The ablation separates suppressing obsolete evi- dence from supplying a usable answer.
