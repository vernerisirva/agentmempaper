Quality reviewed

The work provides a well-executed domain adaptation and detection pipeline that solves a concrete problem in historical astronomical archive preservation, backed by sound ablation studies and solid independent validation via Gaia DR3 astrometric calibration.

The authors document residual dependency on reference catalog depth, sensitivity degradation for the faintest sources, failure on extended comet plates with trailed stars, and caution that instrumental magnitude rank correlations do not constitute calibrated photometry.

    Historical astronomical plates provide a long temporal baseline for time-domain astrophysics, but degradation and structural artifacts can hinder automated astrometric calibration. We present Plate- YOLO, a framework that combines source detection and stellar classification in one detector and supplies source catalogs to a separate astrometric solver. The detector adapts YOLOv5 with Space-to- Depth feature rearrangement, SimAM attention, a high-resolution P2 head, and a Normalized Wasser- stein Distance loss for small bounding boxes. A Gaia-guided fine-tuning procedure uses initially solved plates to construct labels for a new archive. On 150 UBAI plates for which the conventional pipeline had failed, the Chinese-trained model solved 40 plates, and target-archive fine-tuning recovered a fur- ther 106, giving an overall recovery rate of 146/150 (97.3%).
