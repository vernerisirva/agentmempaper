Abstract / summary

Research Paper Agent is an open-source Retrieval-Augmented Generation (RAG) tool for academic literature review. Users upload PDF research papers, which are parsed, chunked, and embedded locally using a sentence-transformer model, then indexed in a local ChromaDB vector store.
