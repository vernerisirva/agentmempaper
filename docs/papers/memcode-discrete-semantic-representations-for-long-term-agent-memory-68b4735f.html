Quality reviewed

The work presents a clear, well-supported technical contribution to agentic memory architecture. Extensive ablations rule out trivial candidate budget increases, and codebook behavior is analyzed extensively without circular optimization.

The authors clearly delineate boundaries: AMU extraction struggles with implicit motivation/affect compared to full-context methods, HippoRAG2 comparison was static rather than dynamic online maintenance, and performance varies with backbone generation verbosity.

    Long-term memory remains a fundamental bottleneck for large language model (LLM) agents across sessions. Existing systems typically adopt a write-then- retrieve paradigm, storing context-dependent dialogue fragments and retrieving them via nearest-neighbor search in continuous embedding space. This design yields unstable access units and systematically misses logically related but lexi- cally distant evidence. We propose MemCode, a long-term agent memory frame- work that couples retrieval-oriented writing with discrete associative retrieval. MemCode rewrites dialogue into self-contained atomic memory units (AMUs), maps AMUs into a learnable codebook with isomorphic semantic quantization (ISQ), and uses codebook co-occurrence topology as a retrieval path comple- mentary to vector search.     A Limitations MemCode targets retrieval-intensive long-term conversational memory, not fully deployed agents with planning, tool use, and interactive adaptation. Its LLM-based AMU writing can miss or distort implicit motivations, emotions, and pragmatic cues; these cases explain why full-context methods remain competitive on LoCoMo Open and bound our claims to structured memory retrieval. Our HippoRAG2 comparison also measures one-shot graph construction over complete LoCoMo histo- ries; repeated graph maintenance in a growing online memory is outside the present evaluation.
