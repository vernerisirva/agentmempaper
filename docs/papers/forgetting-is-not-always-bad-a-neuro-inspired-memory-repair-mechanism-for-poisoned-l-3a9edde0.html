    A Limitations DREAM relies on a multi-dimensional activation probe to distinguish suspicious memories from benign ones. In principle, if an attacker had detailed knowledge of this internal probing mechanism, they could attempt to optimize poisoned memories to remain stable under the probe and thereby weaken the resulting anomaly signal. However, such a probe-aware attack is difficult under the threat models considered in current memory-poisoning work on LLM agents. Existing attacks are typically studied under more constrained capabilities, such as query-only interaction, indirect memory injection through normal user queries, limited write access to the memory store, or black-box access to the agent core, rather than full visibility into the defender's internal monitoring mechanism.
