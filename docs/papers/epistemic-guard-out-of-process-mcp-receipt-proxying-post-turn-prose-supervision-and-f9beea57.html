Abstract / summary

Language-model agents using the Model Context Protocol (MCP) face three runtime verification gaps: (i) action fabrication, where post-tool prose narrates side effects that failed, timed out, or never ran; (ii) provenance collapse, where unverified model prose or web text enters durable memory alongside executed tool...

Quality reviewed

The work presents an adequately scoped, well-architected systems and runtime verification contribution with extensive reproducible conformance and empirical evaluation.

The authors clearly outline limitations, including the restriction to stdio MCP transports, reliance on downstream servers not faking ok=true payloads, degradation of deduplication on heavy/abstractive rewrites, and elevated false positive rates on custom unmapped tool stems.

Publication: preprint. arXiv manuscript identifier; no external publication established by the available metadata.
