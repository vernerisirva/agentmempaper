Abstract / summary

Long-term memory enables embodied agents to reuse past observations across tasks. However, existing cross-episode vision-and-language navigation (VLN) benchmarks often leave it unclear whether successful navigation relies on historical memory or current exploration. Quality reviewed

The benchmark addresses a clear gap in cross-episode navigation benchmarks by making memory strictly necessary rather than optional. The experimental setup is thorough, the proposed baseline is soundly constructed and ablated, and the conclusions are well-supported without overclaiming.

The authors clearly acknowledge benchmark limitations, specifically the restriction to single-floor environments in simulation and reliance on drift-free simulator ground-truth odometry.
