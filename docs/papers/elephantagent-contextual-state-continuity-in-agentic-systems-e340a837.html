Why included

Focuses on persistent or long-term memory for agent behavior.

Abstract / summary

Agentic systems enhance their capabilities by invoking external tools and maintaining persistent memory. However, these external dependencies introduce novel attack surfaces. Recent tool and memory poisoning attacks show that maliciously crafted tool descriptors and poisoned memory can covertly bias agent behavior....

Quality reviewed

The work provides a complete, well-reasoned systems security contribution with formal guarantees, sound implementation in DeepSeek Harness, robust experimental validation against actual attack vectors, and explicit threat boundary considerations.

The authors clearly delineate the boundary of contextual state protection, noting that untracked workspace files rely on indirect tool ingestion, and acknowledge the deliberate fail-closed trade-off regarding system liveness during severe disruption.
