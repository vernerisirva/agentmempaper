Quality reviewed

DolphinBench addresses recognized methodology shortcomings in current memory benchmarks (such as prompt retrieval leakage and unverified solvability) with a sound verification loop and multi-dimensional Pareto reporting. The empirical study across model and memory system permutations is sound and complete for a benchmark contribution.

The authors explicitly discuss key constraints, including reliance on synthetic dialogue histories, coverage restricted to three knowledge-work roles, simulated app APIs rather than live web services, modest task action depths, and separated rather than continuous/interleaved ingestion and testing.
