    Long-term memory enables large language model (LLM) agents to provide continuous per- sonalized assistance by retaining user informa- tion across interactions. Existing systems sup- port this process through fact extraction, organi- zation, updating, and retrieval, but largely main- tain memories as independent facts. This fact- centric paradigm may overlook how new facts update, constrain, or conflict with earlier ones, while leaving their applicability, role, and prior- ity for the current request implicit. In this paper, we introduceEvoMemState, a state-centric framework that augments persistent facts with two complementary states: Relational States that capture how facts remain valid and relate to one another as memory evolves, and a Reason- ing State that determines how these facts should be applied to the current request.     To train the Memory State Evolution Policy to generate a Reasoning State from a request and its relevant Relational State, we construct approx- imately 60K question–memory training instances from FEVER (Thorne et al., 2018), SciFact (Wad- den et al., 2020), and PersonaMem (Jiang et al., 2025). For objective questions, we convert the fact-verification tasks in FEVER and SciFact into question-answering instances with supporting ev- idence and reference answers. We then construct user memories that conflict with the objective ev- idence from the perspectives of personal belief, identity, and perceived expertise. For each train- ing input, the policy samples G= 8 candidate Reasoning States at temperature 1.0, with a roll- out batch size of 512 and a global batch size of 4096.
