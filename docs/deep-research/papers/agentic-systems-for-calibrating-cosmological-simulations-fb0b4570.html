    Calibrating a cosmological simulation is an expensive, high-dimensional parameter optimization task. Previous works employ Bayesian optimization for automation, which treats the simulator as a black box and precludes the incorporation of human domain knowledge or workflow into the selection policy. We propose AGENTICTUNER, an agentic calibration pipeline with a present-day large language model serving as the optimizer who proposes the next parameter trial. We show that these agents can achieve competitive calibration performance at a fraction of the CPU cost when they are given informal, human-readable priors (such as codebase, documentation, and heuristic guides that seasoned scientists may possess). We hope this work serves as an early step toward AI scientists that can carry out complex, long-horizon scientific tasks. A starter code is available on GitHub.1

    Loop design.AGENTICTUNERis an agentic simulation calibration system that replaces an acquisi- tion function with an LLM as the optimizer (see Figure 1). The central loop of AGENTICTUNERis orchestrated by the external harness, which is separate from and independent of the LLM. Each iteration t begins with the instantiation of a stateless LLM instance within a sandboxed container that conceals the hidden ground truth θtrue. Because LLM performance has been shown to deteriorate with a monotonically increasing context window [8, 27, 26], we opt to clear the context [3] after the LLM calls an expensive simulator for the proposed trial θt+1. When the simulation is finished, the harness mediates the evaluation process by calculating ˜χ2(θt+1) and either restarting the loop with a fresh agent or stopping the search if˜χ2 <1or a fixed CPU-hour budget is exhausted.     In this work, we present AGENTICTUNER, an agentic calibration system that uses an LLM agent to propose the parameter point based on trial history and human-authored priors. We evaluate our system in calibrating a costly cosmological simulation and find that AGENTICTUNERoutperforms the Bayesian optimization baseline in simulation cost across all runs. Auditing the reasoning trace of the LLM agent demonstrates its ability to adapt the search strategy during a run from active tool use to synthesizing previous findings. These results suggest that natural-language priors significantly improve the selection process.
