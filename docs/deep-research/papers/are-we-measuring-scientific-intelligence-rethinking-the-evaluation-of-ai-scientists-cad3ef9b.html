These benchmarks assume that a correct answer was derived from the supplied data, a property we callevidence grounding. For each question, we build versions of its data files in which the evidence for the answer is left intact, withdrawn or reversed, check each edit with a pre-registered reference statistic, and run the same agent on every version.     Canonical source evidence
    We propose to evaluate AI scientists by whether their answers follow the evidence, and to test evaluators in the same way. Our approach rests on one observation and one design principle. The observation is that whether an answer came from the data is a counterfactual property, which no evaluation of a single run can establish (Sec. 4.1). The principle isone set of pairs, two audits. We pair each item with versions of its data whose correct response is verified (Sec. 4.2), and use the same paired runs to audit both the agent and the evaluator (Sec. 4.3).
