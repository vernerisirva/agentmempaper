Abstract / summary

Organizing long-term memory for multimodal agents remains challenging because existing methods either suffer from expensive question-agnostic offline summaries or naive embedding similarity matching that introduces incomplete and redundant context. Quality reviewed

GraphMemix provides a rigorous, self-contained formulation solving clear limitations of existing multimodal RAG and offline memory summarization methods, validated comprehensively across diverse datasets and metrics with appropriate controls and ablations.

The manuscript notes boundary conditions regarding dependence on bounded candidate graph recall, reliance on prompt-following structured JSON generation for verifiers, and fixed budget constraints.
