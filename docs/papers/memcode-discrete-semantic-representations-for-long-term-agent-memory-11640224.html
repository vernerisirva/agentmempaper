Quality reviewed

The paper provides an innovative, technically sound, and well-executed architecture for agent memory retrieval that addresses geometric limitations of purely dense representations. Experimental methodology is thorough and well-controlled with extensive ablations.

The authors clearly acknowledge the boundary conditions of AMU abstraction, noting that implicit emotional or pragmatic cues can be lost compared to full-context baselines, and that the evaluation focuses on conversational memory retrieval rather than agentic planning or dynamic multi-step graph updates.

    Long-term memory remains a fundamental bottleneck for large language model (LLM) agents across sessions. Existing systems typically adopt a write-then- retrieve paradigm, storing context-dependent dialogue fragments and retrieving them via nearest-neighbor search in continuous embedding space. This design yields unstable access units and systematically misses logically related but lexi- cally distant evidence. We propose MemCode, a long-term agent memory frame- work that couples retrieval-oriented writing with discrete associative retrieval. MemCode rewrites dialogue into self-contained atomic memory units (AMUs), maps AMUs into a learnable codebook with isomorphic semantic quantization (ISQ), and uses codebook co-occurrence topology as a retrieval path comple- mentary to vector search. Each AMU serves as a minimal semantic unit that can be independently retrieved. Independent semantic quantization (ISQ) anchors each AMU to a discrete symbolic state within a learnable codebook.     A Limitations MemCode targets retrieval-intensive long-term conversational memory, not fully deployed agents with planning, tool use, and interactive adaptation. Its LLM-based AMU writing can miss or distort implicit motivations, emotions, and pragmatic cues; these cases explain why full-context methods remain competitive on LoCoMo Open and bound our claims to structured memory retrieval. Our HippoRAG2 comparison also measures one-shot graph construction over complete LoCoMo histo- ries; repeated graph maintenance in a growing online memory is outside the present evaluation.
