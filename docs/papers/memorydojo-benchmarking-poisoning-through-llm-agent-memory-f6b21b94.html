Evaluates memory mechanisms or benchmarks for LLM agents.

Abstract / summary

LLM agents benefit from using memory systems to improve performance on long-horizon, multi-session tasks. However, memory introduces a critical attack surface. Quality reviewed

The study provides clear experimental controls, detailed lifecycle metrics, rigorous ablation across domains and models, and an auxiliary-to-evaluation transfer setup that prevents circular evaluation.

The work explicitly documents key boundaries, including restricting tasks to sandboxed environments, single-point poison insertion, evaluation on five specific open-source memory configurations, and leaving multi-injection attacks and defensive countermeasure designs for future research.

    We construct multi-session trajectories using task templates from AgentDojo (Debenedetti et al., 2024) across four domains: Workspace, Travel, Banking, and Slack. Each domain provides a stateful environment and tools for interacting with it. All tasks specify an objective and utility check that determines whether the objective is achieved. We concatenate tasks into trajectories, treating each task execution as a separate session while carrying environment state forward. To ensure the concatenated tasks remain executable, we check task pairs for state conflicts and validate each complete sequence. For each domain, we also define an attacker objective ψ, accompanied by a textual description of the behavior that the poison seeks to induce. Using these tasks and conversation histories from LongMemEval-S (Wu et al., 2025), we obtain a dataset with three different collections.
