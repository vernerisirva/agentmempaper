    This study investigated how object -size-aware dataset partitioning affects the performance and reliability of YOLOv11n -based license-plate detection. The findings show that detector performance is influenced not only by the model and training configuration but also by the distribution of object scales across the training, validation, and testing subsets. The natural unsorted splits provided a relatively stable baseline when object-scale diversity was preserved, with mAP@0.50:0.95 reaching approximately 0 .497 in Dataset 1 and ranging from 0.451 to 0.514 in Dataset 2. In contrast, size -ordered partitioning caused substantial performance degradation, reaching a near-collapse value of 0.005 under the most severe scale mismatch.
