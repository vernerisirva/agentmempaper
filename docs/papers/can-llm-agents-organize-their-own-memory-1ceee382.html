    Information about the same person, activity, or task can accumulate across many interactions, and later observations may change how earlier information should be grouped. Predefined memory schemas constrain how this grouping can change (Xu et al., 2025), while storing information as isolated records can leave related evidence scattered across separate items (Ji et al., 2026). We therefore let the agent organize memory in editable, linked documents whose subjects and internal structure can evolve with the content. At update t, the system archives new interac- tion records xt as Source records, preserving their original content for later reference. The agent uses Source and existing memory to update Topic and Core: St = Append(St−1, xt), (Tt,C t) = Organize(St,T t−1,C t−1).
