Abstract / summary

Long-lived LLM agents need memory, and the field's two answers both lack guarantees: retrieval-based memory cannot promise that superseded facts stay retired or that deleted facts stop influencing answers, while parametric memory cannot promise bounded forgetting or auditable deletion.
