Abstract / summary

Agent memory systems must discard stored information when their history exceeds a fixed token budget. Existing budget-accuracy frontiers quantify the resulting loss in accuracy, but do not distinguish irreversible losses caused by eviction from recoverable retrieval failures.     The study evaluates four eviction policies at three budgets and under two retrieval regimes on one benchmark, following a protocol frozen before measurement.
