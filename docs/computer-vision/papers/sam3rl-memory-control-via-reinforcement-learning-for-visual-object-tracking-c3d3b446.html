Abstract / summary

Segment Anything Model 3 (SAM 3) is a foundation model for image and video segmentation that sets the state of the art in visual object tracking. Its tracker, inherited from SAM 2, stores information from past frames in a memory bank, managed by a simple First-In-First-Out rule, allowing temporal consistency in comp...

Quality reviewed

This is a rigorous, high-quality empirical study that identifies and fixes undocumented issues in foundation tracking models, systematically evaluates across standard benchmarks, and validates design choices via complete ablations.

The authors explicitly discuss limitations regarding fixed stride matching pre-known frame rates, the lack of full joint learning for auxiliary object pointers, and qualitative failure cases during rapid viewpoint/scale changes.

    SAM3RL: Memory Control via Reinforcement Learning for Visual Object Tracking Training data.We train on the LaSOT training split (Fan et al., 2019), whose 1,120 sequences are divided into 896 for training and 224 for validation, while the official test set is held out. LaSOT is annotated with per-frame bounding boxes at 30 FPS. Since consecutive frames at that rate are nearly identical, an eviction decision changes the bank very little while still consuming a decision step. We therefore subsample every sixth frame, so that training episodes run at 5 FPS and span 425 decision steps on average. This also matches the typical annotation rate of VOS datasets. Optimization.We train the controller with Proximal Policy Optimization (PPO) (Schulman et al., 2017), using the undiscounted Monte-Carlo return (i.e.,γ= 1) minus the critic's predicted value as the advantage.     We presented SAM3RL, which learns memory control over a fixed-capacity bank with RL while keeping the backbone frozen. SAM3RL improves over SAM 3 on 11 of 12 benchmarks and ranks first on 10, with the largest gains on VOT(S), at virtually no runtime cost. It is also the only method that consistently improves on video object segmentation. Applying the same recipe to SAM 2 yields SAM2RL, which improves over SAM 2 on every benchmark and leads on 9. We therefore match the training rate with the strides, which requires the frame rate to be known in advance and keeps the skipped frames out of the memory bank. The former is rarely restrictive in practice, as the frame rate is usually available. Training at the native rate would remove this restriction, but most decisions would then concern near-identical frames. Such a policy could nonetheless exploit the skipped frames and improve further on high-frame-rate benchmarks. Second, the policy controls only the seven frames in the memory bank, while the nine object pointers are filled by a fixed rule. Learning both jointly is a natural direction for future work.
