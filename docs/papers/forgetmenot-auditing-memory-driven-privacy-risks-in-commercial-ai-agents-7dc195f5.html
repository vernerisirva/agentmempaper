Abstract / summary

Commercial AI agents increasingly incorporate long-term memory (both persistent and chat-history) to enable more accurate and personalized responses, raises significant privacy and policy concerns. Quality reviewed

The study provides a rigorous, well-controlled measurement audit of black-box commercial agent memory systems, addressing key methodological hurdles like attribution via canary values and evaluator verification against human agreement.

The authors document scope limitations honestly, noting reliance on two synthetic personas, free-tier interfaces, platform evolution over time, and non-exhaustive adversarial prompt exploration rather than adaptive worst-case jailbreaks.

    As discussed in Section 6.1, we adopt a reference based LLM-as-a-Judge approach, motivated by prior work [5], where each response is evaluated against the correspond- ing attribute values. We use GPT-4.1 and GPT-4.1-mini as judges through OpenAI API [91]. For cost effectiveness (by 25%), we use a two stage LaaJ pipeline. Stage-1 evaluates every response using only the ground-truth of the queried attribute, assigning labels while flagging responses that may contain other leakage. Stage-2 analyzes only flagged responses using a retrieved subset of the persona's cate- gorized memory.
