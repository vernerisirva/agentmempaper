    Memory overlaps with retrieval-augmented generation (RAG) and long-context mod- eling, but it is not identical to either.     Long-term memory often contains personal, proprietary, or task-sensitive informa- tion. Multi-user, multi-agent, and edge–cloud settings require access control, prove- nance tracking, permission-aware retrieval, conflict management, secure deletion, and privacy-preserving personalized memory management (Chen et al. 2026c). Paramet- ric memory is especially challenging because a single remembered fact may not be directly inspectable or removable. Practical memory systems should therefore expose deletion logs, memory scopes, user consent controls, and policy-aware retrieval filters. 24 These governance mechanisms should be treated as core technical components rather than deployment afterthoughts.

    Current benchmarks cover long-context retrieval, conversational memory, multimodal understanding, and simulation environments, but evaluation remains fragmented. Future benchmarks should measure memory write quality, update correctness, absten- tion, hallucinated memory use, privacy leakage, temporal consistency, and downstream task success. They should also distinguish between genuine memory use and success through long-context pattern matching. One practical approach is to evaluate agents under controlled memory ablations, where memory contents are removed, corrupted, delayed, or replaced to test whether the model truly depends on the intended memory mechanism.

    Memory research for LLMs has moved from simple retrieval augmentation toward a diverse ecosystem of nonparametric stores, graph memories, multimodal memories, parametric memory modules, and self-evolving agent systems. This survey organized the literature around a lightweight cognitive-science-inspired conceptual motivation layer, three computational mechanism families—nonparametric memory, parametric memory, and memory for agent evolution—and a cross-cutting evaluation layer that tests whether these mechanisms produce durable benefits.
