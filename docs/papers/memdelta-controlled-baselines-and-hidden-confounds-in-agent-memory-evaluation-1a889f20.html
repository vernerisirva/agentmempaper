Quality reviewed

The manuscript presents a rigorous, well-designed measurement study that cleanly exposes critical methodological confounds in LLM agent memory evaluation with substantial empirical support and controlled statistical contrasts.

The authors clearly acknowledge key limitations, including restricting the Mem0 comparison to 88 instances across 2 question types due to write-path compute costs, reliance on synthetic benchmark dialogues, and approximate rather than identical embedding matching for Mem0.

    All accuracy judgments use GPT-4o-mini with a binary prompt: given the ground-truth answer and the model's response, output YES if the response contains the correct information, NO otherwise. The judge does not see the question context or memory, only the ground truth and the candidate answer. This avoids inflating scores for verbose but incorrect responses.
