Quality reviewed

Despite an informal tech-report tone, the paper presents a concrete, well-specified architectural contribution with rigorous empirical benchmarking on standard computer vision datasets.

The report explicitly acknowledges weaknesses, such as lagging behind state-of-the-art detectors under stricter IoU criteria and failing to improve performance with focal loss or linear coordinate predictions.

    Each box predicts the classes the bounding box may con- tain using multilabel classification. We do not use a softmax as we have found it is unnecessary for good performance, instead we simply use independent logistic classifiers. Dur- ing training we use binary cross-entropy loss for the class predictions. This formulation helps when we move to more complex domains like the Open Images Dataset [7]. In this dataset there are many overlapping labels (i.e. Woman and Person). Using a softmax imposes the assumption that each box has exactly one class which is often not the case. A multilabel approach better models the data.

    YOLOv3 predicts boxes at 3 different scales. Our sys- tem extracts features from those scales using a similar con- cept to feature pyramid networks [8]. From our base fea- ture extractor we add several convolutional layers. The last of these predicts a 3-d tensor encoding bounding box, ob- jectness, and class predictions.
