    Large language model (LLM) agents rely on external memory to retain and reuse informa- tion across interactions. Existing memory sys- tems treat memory as a record of the past and evaluate it by fidelity to the conversation. How- ever, the value of memory lies in whether it im- proves the agent's response. A memory system decides what to memorize and what to serve before that response exists, and fidelity checks neither decision against it. Faithful memory can therefore fail to improve the response. We instead view memory as a prediction problem and presentLeto, a memory system for LLM agents that focuses on the utility of memory to the future rather than on its fidelity to the past. Because future requests are unknown,Letopre- serves access to conversation details through memory indexing, allowing information to re- main available through its sources. Keeping every conversation beneath the fact index removes the loss of discarded de- tail, but it does not make every detail reachable: a message that no fact points to is served only when another fact's source contains it. Extraction cov- erage therefore remains the bound on how far the memorization gap can be closed. Serving standing information before the request bridges the serving gap where a request leaves a standing constraint unstated, at the cost of context that a given request may not need.
