    SkillBuffBench measures whether Skills raise task success for agents working in realistic conditions, and whether that effect survives changes of harness, task domain and memory setting. Three questions organise the design: RQ1Does acuratedSkill improve task success over no Skill? RQ2 Doesautomatic invocationfrom an installed Skill library improve task success over no Skill, and how much of the curated gain does it retain? RQ3 Does memory change task success, cost, number of agent rounds or wall-clock time, and does it change the effect of Skills? The experiment is a full factorial over four factors, summarised in Table 1 and Figure 2, evaluated on a fixed suite of 4 tasks with three repeats per cell.
