Abstract / summary

An AI assistant's long-term memory, built week by week from one real mailbox, with every intermediate layer kept. One Enron employee's email (the kaminski-v mailbox of the public CMU Enron corpus: 11,523 messages, 30 November 1999 to 3 February 2002) is replayed in the order it arrived into a file-based agent memory...
