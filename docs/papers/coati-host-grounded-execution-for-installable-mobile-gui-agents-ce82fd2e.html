Abstract / summary

Mobile GUI agents can carry out tasks across apps, yet most run on a separate computer that drives a phone over the Android Debug Bridge (ADB), out of reach of ordinary users and of the apps through which most people reach Web services. We present Coati, a source-available agent that users install as an Android app....

Quality reviewed

The work presents a clearly articulated systems contribution with rigorous benchmarking against baseline implementations under strict, controlled step and access constraints, supported by targeted ablation and hardware deployment studies.

The authors document key limitations including sensitivity to fast exploration on deep routes, hardware dependencies for local GPU OCR, reliance on external LLM endpoints for privacy-sensitive data, and restrictions on AccessibilityService distribution.

We presentCoati, a source-available Android agent that users in- stall as an app. Coati is designed to address the reliability, execution- efficiency, and repeated-use challenges of installable mobile agents. Its core principle ishost-grounded execution: the model proposes an action, while evidence recorded by the host—the information col- lected by Coati's runtime on the phone—determines the outcome.
