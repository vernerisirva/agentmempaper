    We introduceNeural Procedural Memory (NPM), a training-free framework designed to in- ternalize agentic skills directly into the model's activation space. The framework shown in Fig- ure 2 consists of three phases: (1)Contrastive Experience Construction(§3.1), which isolates effective reasoning patterns from historical failures; (2)Steering Vector Extraction(§3.2), which dis- tills discrete textual contrasts into continuous steer- ing vectors; and (3)Inference-Time Intervention (§3.3), where these vectors are dynamically synthe- sized and injected to modulate the agent's behavior.
