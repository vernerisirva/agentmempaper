Quality reviewed

This paper presents an exceptionally well-executed, rigorous benchmark study addressing an important blind spot in conversational agent memory research. The experimental design features solid controls, comprehensive human and multi-judge validation, reproducible prompt templates, and thorough sensitivity analyses.

The authors transparently acknowledge key limitations: the benchmark relies on the original ten LoCoMo conversation sets, conversational rewrites are generated using an LLM pipeline with sample-based human validation, and primary response generation uses a single open-weights model family.

    Limitations and Future Work LOCOMO-CONVhas several limitations. Conver- sational rewrites and supportive_memory annota- tions are generated through LLM-based pipelines and may inherit model-specific biases; human vali- dation (Appendix G) covers a 40-item sample per style rather than the full set. Our evaluation relies on a single open-weights answer model and one primary judge family, with cross-judge and human validation performed on subsets.
