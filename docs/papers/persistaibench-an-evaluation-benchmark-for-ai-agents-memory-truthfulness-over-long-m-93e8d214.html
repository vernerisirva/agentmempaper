Abstract / summary

A benchmark that measures whether AI agents store falsified tool results into long-term memory and act on them later. Deterministic retail world with database ground truth, 5 seeded fault conditions, 6 memory-write policies (M0–M5), fully programmatic scoring (no LLM judge).
