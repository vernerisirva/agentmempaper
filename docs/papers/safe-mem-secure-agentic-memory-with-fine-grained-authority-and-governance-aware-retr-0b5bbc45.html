    Large language model (LLM) agents increas- ingly rely on persistent memory to support long-term reasoning and personalized interac- tions. However, information collected from external sources can introduce security risks when untrusted claims (i.e., atomic statements) are later treated as authorized preferences, policies, or permissions. Existing defenses typically rely on content-based filtering or coarse-grained provenance tracking, which ei- ther fail to prevent unauthorized memory use or block legitimate information, sacrificing mem- ory utility. To address these limitations, we propose SAFE-Mem, a fine-grained memory governance framework that improves security while preserving legitimate memory use.     We consider an LLM agent that serves one or more principals across sessions. While working, the agent reads external artifacts such as web pages, emails, documents and tool outputs, and distills what it reads into persistent memory. In later ses- sions, it retrieves entries relevant to a request and conditions its answer or action on them. Authority over a principal originates only in that principal's own assertions, instructions and authorizations. The agent runtime records the channel through which each input arrives, such as a principal's turn or an attached artifact, and these records are trusted. The adversary controls the content of external artifacts the agent reads.     SAFE-Mem describes every claim c by three gov- ernance labels: a kind κ(c), an authority α(c) and a scopes(c). The kind specifies what a claim does when the agent adopts it, following Searle's classification of illocutionary acts (Searle, 1976). A description reports what a source asserted and binds nobody. An attribute commits its speaker to a fact about a subject and binds answers about that subject. Pref- erences and rules function as directives but differ in reach: a preference guides choices made for a principal, while a rule governs every occasion that satisfies its condition. A permission functions as a declaration, changing what the agent may do or whom it may rely on by being issued.     Canonical source evidence
    Defenses that act through the model's judgment are as strong as the model that applies them. Without defense, GPT-5.6-terra resists more attacks than GPT-4o-mini, with ASR of 26.7% against 49.8%, and A-MemGuard removes half of the attacks on GPT-5.6-terra but under a fifth on GPT-4o-mini. The same dependence appears inside SAFE-Mem when inadmissible entries are served with a descrip- tion label: ASR rises from 2.6% and 6.2% to 6.2% and 19.6% (Appendix M). Withholding decides what reaches the context, and with it SAFE-Mem's ASR stays between 1.5% and 6.2% across all four backbones (Table 1). The judgments that set the labels hold up against human labels (Appendix I): the use classifier separates descriptions from every higher kind on 94.0% of requests on GPT-5.6-terra, the retention judgment agrees on 84.0% of prin- cipal sentences, and the answer judge agrees on 83.5% of answers.
