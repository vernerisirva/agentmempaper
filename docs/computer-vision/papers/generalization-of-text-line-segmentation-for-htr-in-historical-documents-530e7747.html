    We usemean average precision(mAP) as a metric to evaluate the performance of our object detection networks. It is defined as mAP= 1n nX i=1 APi where APi is the average precision for class i (in our case, n= 1 as we are only predicting text lines). The average precision is defined as the area under the precision-recall-curve. To define the alignment of predictions and ground-truth (GT) annotations, an Intersection over Union (IoU) threshold is determined. We compute the mAP50:95 metric, which takes the average for all IoU thresholds from 0.50 to 0.95 in incremental steps of step width 0.05. The higher this value, the closer the alignment of predictions and GT boxes. While mAP is commonly used to evaluate object detection models, we ultimately have text recognition in mind as the downstream task. We evaluate the quality of HTR with the Character Error Rate (CER): CER= S+I+DN ,(1) which is based on the Levenshtein edit distance [14]. CER quantifies the number of character-level operations required to transform the predicted text into the ground-truth. It is computed as the ratio of the total number of substitutions (S), insertions (I), and deletions (D) edits to the number of characters (N) in the ground-truth. Lower CER values indicate better recognition performance, reflecting fewer discrepancies between the predicted and reference text. To compute the CER for the predicted text lines, the corresponding ground-truth text must first be identified.
