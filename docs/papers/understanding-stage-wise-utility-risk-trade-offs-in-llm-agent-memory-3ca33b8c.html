Quality reviewed

The manuscript offers a rigorous, well-controlled experimental framework addressing a major gap in agent memory security evaluations, supported by broad cross-model testing, sensitivity analyses, and expert human annotation validation.

The authors acknowledge that existing memory architectures couple stages tightly, meaning real-world system experiments represent diagnostic associations rather than strictly isolated stage controls.
