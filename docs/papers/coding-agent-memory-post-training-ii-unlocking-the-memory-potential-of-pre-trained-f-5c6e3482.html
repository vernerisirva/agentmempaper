Why included

Studies governed shared memory or persistent memory protocols for LLM agents.

Abstract / summary

Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the model's active context. They must therefore decide what to write down and what to read back, and when to do either. Recent work has begun to use on-policy distillation (OPD) to make memory control part of the policy,...

Quality reviewed

The manuscript presents a rigorous investigation into leveraging filesystem priors for language agent memory distillation, supported by extensive baseline comparisons, multi-seed training runs, mechanistic ablations, and external benchmark validation.

The authors explicitly state limitations regarding evaluation scope, noting that experiments were restricted to models up to 9B parameters with a single frozen 27B teacher, leaving larger scales and multi-teacher distillation unexamined [E39fdd122f4b637a4-B0043].

    A CAMG-II Environment Details CAMG-II contains five environments built around long-horizon tasks in which information obtained early can matter after the active context is replaced. Shop composes new multi-session tasks from WebShop products. Coding, AutoResearch, General, and Visual select executable tasks from SWE-smith, public OpenMLE task packages, and MiMo's enterprise and website collections, respectively [ 37, 66, 70]. Each environment preserves its domain interaction and definition of task success. CAMG-II adds a bounded active context and an episode-private workspace that persists across context replacement.
